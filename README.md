# 🛍️ TokoKu - Premium WhatsApp Store Theme (v1.7.3)

**TokoKu** adalah tema WordPress premium yang dirancang khusus untuk toko online minimalis dengan sistem pemesanan langsung melalui WhatsApp. Tema ini menghilangkan kerumitan WooCommerce, memberikan pengalaman belanja yang cepat, ringan, dan sangat intuitif baik di perangkat mobile maupun desktop.

---

## ✨ Fitur Terbaru v1.7.3
*   **Elegant Top Button**: Penggantian ikon Scroll to Top dengan SVG Chevron yang lebih modern dan elegan, diposisikan secara melayang di atas tombol WhatsApp.
*   **Clean Desktop UI**: Penghapusan batang gulir (scrollbar) default browser pada tampilan desktop untuk memberikan kesan antarmuka yang lebih "seamless" dan premium.
*   **Glassmorphism UI**: Implementasi efek kaca (blur & transparansi) pada tombol kembali ke atas untuk estetika yang lebih canggih.
*   **Advanced Hover Animations**: Efek transisi halus dan animasi hover pada seluruh elemen aksi melayang.

---

## ✨ Fitur v1.7.2
*   **Mobile UI Restoration**: Restorasi navigasi bawah (bottom nav) khusus mobile kembali ke gaya versi 1.6.7 (4 menu: Home, Kategori, Pencarian, WhatsApp).

---

## ✨ Fitur v1.7.1
*   **Floating Layout Fix**: Perbaikan tata letak tombol melayang. Tombol WhatsApp dan Scroll to Top kini berada dalam satu container yang sejajar secara vertikal.

---

## ✨ Fitur v1.7.0
*   **Scroll to Top Button**: Penambahan tombol "Kembali ke Atas" otomatis untuk memudahkan navigasi di halaman yang panjang.

---

## ✨ Fitur v1.6.7
*   **Core Security Hardening**: Penambahan sistem keamanan `ABSPATH` check pada seluruh file tema untuk mencegah akses file langsung secara ilegal.
